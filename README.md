# زرین‌دانه — فروشگاه آنلاین سوغات و خشکبار اصیل ایران
# Zarindaneh (Persian Gourmet Heritage E-Commerce)

یک وب‌اپلیکیشن فروشگاهی مدرن، واکنش‌گرا و سریع پیاده‌سازی شده با **React 19 + TypeScript + Vite + Tailwind CSS**.

## ویژگی‌های کلیدی
- **صفحه نخست (Home):** بنر معرفی زعفران سوپر نگین، نوارهای تضمین کیفیت و عیار آزمایشگاهی، گرید دسته‌بندی‌ها، پرفروش‌ترین‌ها، داستان اصالت و سرتیفیکیت‌ها.
- **فروشگاه و کاتالوگ (Products):** فیلتر آنی دسته‌بندی‌ها (زعفران قائنات، پسته و خشکبار، گز و سوهان، عسل، پک هدیه)، جستجوی زنده، مرتب‌سازی قیمتی و امتیازی.
- **صفحه اختصاصی محصول (Product Detail):** گالری چندتصویره با پیش‌نمایش بزرگ‌نمایی، انتخاب وزن/بسته‌بندی با به‌روزرسانی قیمت، شمارنده تعداد، تب‌های شناسنامه آزمایشگاهی و نظرات.
- **سبد خرید پویا (Cart):** مدیریت اقلام، محاسبه خودکار تخفیف و ارسال رایگان (بالای ۵۰۰ هزار تومان)، کد تخفیف (`ZARRIN10`) و امکان ارسال سبد به تلگرام.
- **تسویه حساب و پرداخت (Checkout):** فرم دریافت اطلاعات تحویل‌گیرنده و نشانی پستی، انتخاب روش ارسال، انتخاب درگاه بانکی شتاب یا کارت‌به‌کارت.
- **صدور فاکتور و پیگیری (Order Success):** دریافت کد رهگیری فاکتور (ZR-XXXXX)، قابلیت چاپ فاکتور (`window.print()`) و تایید در تلگرام.
- **داستان ما و مزارع (About):** پیشینه چهار دهه زرین‌دانه، مزارع قائنات و باغات رفسنجان.
- **تماس و شعب (Contact):** اطلاعات شعب تهران و مشهد، ساعات کاری و فرم ثبت پیام.

## راه‌اندازی و اجرا

```bash
# نصب وابستگی‌ها
npm install

# اجرای سرور توسعه روی پورت ۳۰۰۰
npm run dev

# ساخت نسخه پروداکشن
npm run build
```
